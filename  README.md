# 🚀 Snippets Bot

Элегантный и быстрый Telegram-бот для сохранения, категоризации и быстрого поиска ваших кодовых сниппетов и текстовых заметок по хештегам. Идеальный инструмент для разработчиков, которым нужно держать важные фрагменты кода под рукой.

## ✨ Ключевые фичи

- **Организация по тегам:** Полное управление базой знаний через удобные инлайн-меню.
- **Интуитивный UI/UX:** Пошаговое добавление заметок (FSM) с возможностью отмены.
- **Быстрый доступ:** Просмотр и удаление сниппетов в один клик прямо из чата.
- **Production-Ready:** Проект полностью готов к деплою через Docker и контейнеризирован.

---

## 🛠 Технологический стек

- **Язык:** Python 3.11+
- **Фреймворк:** Aiogram 3 (Асинхронный подход)
- **База данных:** SQLite / Asyncpg
- **Сборка и окружение:** Docker, Docker Compose
- **Декларативное управление:** NixOS (Flakes)

---

## 🚀 Быстрый запуск

### Вариант 1. Через Docker (Рекомендуемый)

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте файл `.env` в корне проекта и добавьте ваш токен:
```

BOT_TOKEN=your_telegram_bot_token_here

```
3. Запустите контейнер:
```bash
docker-compose up -d

```

### Вариант 2. Локальный запуск (NixOS / DevShell)

Если вы используете NixOS, окружение со всеми зависимостями уже настроено в Flake:

```bash
python -m bot.main

```
